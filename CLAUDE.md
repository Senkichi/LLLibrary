# LLLibrary — operating rules

This is a public knowledge base of LLM evaluation and agent systems lessons.

## Layout

- `wiki/` — content pages with `[[wikilink]]` cross-references (Obsidian-vault compatible)
- `wiki/anatomy.md` — flat sitemap
- `wiki/index.md` — themed navigation

## Frontmatter schema

Every page has:

```yaml
---
title: <human-readable title>
created: YYYY-MM-DD
last-reviewed: YYYY-MM-DD
last-modified: YYYY-MM-DD
tags: [tag1, tag2]
provenance: <source project(s)>
---
```
