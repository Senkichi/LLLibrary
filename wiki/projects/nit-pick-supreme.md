# nit-pick-supreme

A federated code review tool. Multiple analysis engines (architectural review,
language-specific linting, frontend/backend specialists, security review) run
in parallel against a target codebase. Each engine emits findings into a
unified schema. A coordinator merges, deduplicates, and prioritizes across
engines.

## Why this is referenced

- `wiki/patterns/federated-review-engines.md` — the federated-engines pattern
  and its unified findings schema were extracted from nit-pick-supreme.

## Status

Private codebase. Not publicly available. This stub exists so wikilinks from
the public pages resolve to a description of what the source project is.
