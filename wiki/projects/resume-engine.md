# resume-engine

A private personal pipeline for tailoring and scoring job applications: scraping
postings, generating tailored resumes, scoring outputs against the source
posting, and tracking application status.

## Why this is referenced

Several pages in this knowledge base draw lessons from `resume-engine`:

- `wiki/patterns/python-derived-classification.md` — the deterministic-verdict
  pattern was extracted from resume-engine's scoring layer.
- `wiki/workflows/failure-mining.md` — multiple incidents in resume-engine
  contributed to the broader failure-category taxonomy.

## Status

Private codebase. Not publicly available. This stub exists so wikilinks from
the public pages resolve to a description of what the source project is.
